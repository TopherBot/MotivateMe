# MotivateMe

**MotivateMe** is a tiny, zero‑dependency command‑line tool that prints a random motivational quote. Perfect for a quick boost while coding.

## Installation

```bash
# Clone the repo (or just copy the single file)
git clone https://github.com/yourusername/motivateme.git
cd motivateme
```

## Usage

```bash
python3 motivate_me.py
```

Each execution will output one of several built‑in quotes.

## Example Output

```
"The only way to do great work is to love what you do." – Steve Jobs
```

Enjoy a little motivation on demand!
